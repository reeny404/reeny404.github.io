# 포트폴리오를 사이드 프로젝트로 다시 만들기 (4) 사이트 전체에 실행 취소 넣기

> 초안. `[다듬기]`는 본인 의견으로 채울 부분.

## 아이디어

PlotPlan 에디터 V2에서 가장 중요한 결정은 "모든 편집은 command를 통과한다"였다. 이 사이트에서도 같은 규칙을 적용하면, 설명을 읽기 전에 손으로 먼저 알 수 있지 않을까.

결과: 테마를 바꾸거나 첫 화면 에디터에서 도형을 옮긴 뒤 ⌘Z를 누르면 되돌아간다.

## 구조

```ts
type Command = { label: string; scope: "site" | "editor"; do(): void; undo(): void };

history.execute(command); // do 실행 후 past에 쌓음
history.undo();           // past의 마지막을 undo, future로 이동
history.redo();
```

- 상태 라이브러리 없이 `useSyncExternalStore`로 구독
- 테마 변경도 command: `setTheme(next)`가 이전 값을 기억하는 command를 만들어 실행
- 입력창에 포커스가 있을 때는 ⌘Z를 가로채지 않음 (텍스트 실행 취소와 충돌 방지)

## 미니 에디터: document와 view 분리

첫 화면 에디터는 PlotPlan 구조를 축소한 것.

- **document**: 도형의 중심 좌표(cx, cy)와 rotation. command로만 바뀜
- **view**: 선택된 도형, 드래그와 회전 중 미리보기, 줌. 저장하지 않는 화면 상태

드래그하는 동안에는 view의 미리보기 값만 바뀌고, 포인터를 놓는 순간 `move` command 하나가 document에 반영된다. 그래서 ⌘Z 한 번이 드래그 한 번을 되돌린다. 드래그 중 pointermove마다 command를 쌓았다면 실행 취소가 수십 번 필요했을 것.

도형 컴포넌트는 `useIsSelected(id)`로 **자기 선택 여부 boolean만** 구독. 다른 도형을 선택해도 다시 렌더링되지 않는다. (5)편의 render 데모와 같은 원칙.

키보드로도 쓸 수 있게 도형은 `role="button"`과 `tabIndex`를 갖고, 방향키 이동과 R 회전도 같은 command를 사용.

## ⌘K 명령 팔레트

- 네이티브 `<dialog>`의 `showModal()`로 포커스 가두기와 Esc 닫기를 브라우저에 맡김
- `role="combobox"` 입력 + `aria-activedescendant`로 선택 항목 전달
- 이동, 테마, 실행 취소, 외부 링크를 한곳에서

## 토스트: 타이머 상태 없이

되돌릴 때 "되돌림: 테마 다크 → 라이트" 토스트를 띄운다. 처음에는 `useEffect` + `setTimeout`으로 숨겼는데, React 19의 lint 규칙(effect 안의 setState)에 걸렸다. 표시 시간을 **CSS animation**으로 처리하고 기록마다 `key`를 바꿔 애니메이션을 다시 시작하도록 변경. hover나 포커스 중에는 `animation-play-state: paused`로 멈춤.

## 회전이 흔들려 보였던 이유

처음에는 도형 위치를 왼쪽 위 좌표로 저장했다. 90도 돌리면 가로세로가 바뀌니 중심을 지키려고 왼쪽 위 좌표도 함께 옮겼는데, 그 이동 애니메이션과 회전 애니메이션이 서로 다른 궤적으로 동시에 돌면서 중심이 잠깐 흔들렸다. 끝에서 살짝 튕기는 spring easing이 흔들림을 더 키웠다.

위치를 **중심 좌표**로 저장하도록 데이터 모델을 바꿨다. 회전 command는 각도 하나만 바꾸고, 화면은 중심으로 translate한 뒤 rotate 하나만 적용한다. 보정할 이동이 없으니 흔들릴 것도 없다. 이 모델 덕분에 90도 단위가 아닌 회전 핸들도 자연스럽게 붙었다. 핸들을 끄는 동안에는 view 상태의 미리보기 각도만 바뀌고, 놓는 순간 rotate command 하나가 기록된다. 이동과 같은 규칙.

경계 각도도 처리했다. document는 0~359도만 저장하므로 350도에서 10도로 가면 화면상 거꾸로 340도를 돌게 된다. 화면에 그리는 각도는 직전 값과의 가장 짧은 차이만 더한 누적 각도로 따로 유지.

## 장비에서 도형으로

처음 에디터는 PlotPlan처럼 탱크, 펌프, 열교환기 모양의 장비와 배관이었다. 실제 경력과 바로 이어진다는 장점이 있었지만, 처음 보는 사람은 이게 에디터인지조차 알기 어려웠다. 누구나 아는 디자인 툴의 도형(사각형, 원, 별, 삼각형, 텍스트)으로 바꾸고 색을 입혔다. 구조(document, command, view 분리)는 그대로이므로 사례와의 연결은 유지된다.

## 글로 설명하지 않기

처음에는 "끌어서 옮기기, ⌘Z 되돌리기" 같은 안내 문구를 에디터 아래에 뒀다가 모두 지웠다. 안내가 필요하다면 UI가 제 역할을 못 하는 것이고, 실행 취소 같은 장치는 발견하는 재미가 있어야 한다. 대신 grab 커서, 선택 테두리와 회전 핸들, 우하단의 실행 취소와 다시 실행 아이콘, 우상단의 초기화 아이콘처럼 화면 자체가 알려 주도록 바꿨다.
