# reeny404.github.io

이효현의 웹 포트폴리오. https://reeny404.github.io

빌드 없는 정적 HTML/CSS. `main` 브랜치 루트가 GitHub Pages로 배포되며, `.nojekyll`로 Jekyll 처리를 끔.

```
index.html            메인: 대표 사례, 경력, 기술, 연락
work/plotplan.html    PlotPlan 에디터 V2
work/chipnsoda.html   ChipNSoDA 실시간 작업 상태
work/miridih.html     미리디 저장과 결제 안정화
assets/css/           tokens.css → base.css → components.css
DESIGN.md             디자인 토큰, 컴포넌트, 문구 규칙
```

로컬 확인: `python3 -m http.server 4000` 후 http://localhost:4000

내용의 근거와 원고는 비공개 저장소 `career-research`에서 관리.
